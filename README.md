# 🤖 កម្មវិធីឆ្លើយតបឆាត Telegram អូតូ (សម្រាប់គណនីផ្ទាល់ខ្លួន)

កម្មវិធីនេះជួយឱ្យគណនី Telegram ផ្ទាល់ខ្លួនរបស់អ្នកឆ្លើយតបសារដោយស្វ័យប្រវត្តិ ពេលមានគេឆាតមក (Private Chat) ដោយមិនប៉ះពាល់ដល់ Group ឬ Channel ឡើយ។

## ✨ មុខងារសំខាន់ៗ
1. **ឆ្លើយតបតាមពាក្យគន្លឹះ និងតារាងសំណួរ (Menu & Keywords)**៖ បង្ហាញបញ្ជីសំណួរ (១ ដល់ ៤) ឱ្យភ្ញៀវជ្រើសរើសដោយគ្រាន់តែវាយលេខ។
2. **ផ្ញើរូបភាពផលិតផលអូតូ (Product Image with Caption)**៖ ផ្ញើរូបភាពផលិតផលជាក់ស្ដែងភ្ជាប់ជាមួយអត្ថបទពន្យល់ភ្លាមៗតាមសំណួរនីមួយៗ។
3. **សំឡេង AI មនុស្សស្រីភាសាខ្មែរ (Khmer AI Voice)**៖ បង្កើត និងផ្ញើសារជាសំឡេងនិយាយភាសាខ្មែរ (សំឡេងស្រីមុំ) ទៅកាន់ភ្ញៀវដោយស្វ័យប្រវត្តិ។
4. **ឆ្លើយតបឆ្លាតវៃជាមួយ AI (Gemini AI)**៖ អាចដាក់ `GEMINI_API_KEY` ដើម្បីឱ្យ AI ជួយអានសារ និងឆ្លើយតបជំនួសដោយស្វ័យប្រវត្តិ។
5. **បញ្ជាបិទ/បើក និងកំណត់ផ្ទាល់ក្នុង Telegram**៖ គ្រាន់តែវាយបញ្ជាក្នុង **Saved Messages**៖
   - `/status` : មើលស្ថានភាពប្រព័ន្ធ
   - `/off` : បិទការតបអូតូ
   - `/on` : បើកការតបអូតូវិញ
   - `/setimage 1..4` : Reply លើរូបភាពដើម្បីកំណត់រូបផលិតផលសម្រាប់សំណួរទី 1-4
   - `/delimage 1..4` : លុបរូបភាពផលិតផលចេញវិញ
   - `/setvoice 1..4` : Reply លើសារសំឡេងដើម្បីកំណត់សំឡេងផ្ទាល់ខ្លួន
   - `/delvoice 1..4` : លុបសារសំឡេងផ្ទាល់ខ្លួន (ប្រើសំឡេង AI វិញ)
   - `/setmsg សារថ្មី...` : ប្ដូរសារពេលរវល់ភ្លាមៗ
   - `/ai on` ឬ `/ai off` : បើក/បិទមុខងារ AI

## 🚀 របៀបរៀបចំ និងប្រើប្រាស់ (៣ ជំហានងាយៗ)

### ជំហានទី ១៖ យក `API_ID` និង `API_HASH` ពី Telegram
1. ចូលទៅកាន់គេហទំព័រផ្លូវការរបស់ Telegram៖ [https://my.telegram.org](https://my.telegram.org)
2. វាយលេខទូរស័ព្ទ Telegram របស់អ្នក (ឧទាហរណ៍ `+85512345678`) រួចវាយលេខកូដដែល Telegram ផ្ញើចូលក្នុងកម្មវិធី Telegram របស់អ្នក។
3. ចុចលើពាក្យ **API development tools**។
4. បំពេញឈ្មោះកម្មវិធីអ្វីក៏បានត្រង់ `App title` និង `Short name` (ឧ. `MyAutoReply`) រួចចុច **Create application**។
5. ចម្លង (Copy) លេខ **`api_id`** និងអក្សរ **`api_hash`** ទុក។

### ជំហានទី ២៖ បំពេញក្នុងឯកសារ `.env`
បើកឯកសារ `.env` ហើយដាក់លេខដែលអ្នកបានចម្លង៖
```env
API_ID=12345678
API_HASH=abcdef1234567890abcdef1234567890
GEMINI_API_KEY=
```
*(ប្រសិនបើចង់ប្រើ AI ជួយឆ្លើយ អាចយក Key ឥតគិតថ្លៃពី [Google AI Studio](https://aistudio.google.com/app/apikey) មកដាក់ត្រង់ `GEMINI_API_KEY`)*

### ជំហានទី ៣៖ ចុចដំណើរការ
- ចុច Double-Click លើឯកសារ **`run.bat`** (ឬវាយ `python bot.py` ក្នុង Terminal)។
- ពេលដំណើរការលើកដំបូង វានឹងសួររក **លេខទូរស័ព្ទ Telegram** (ឧ. `+855...`) និង **លេខកូដ OTP** ដែលផ្ញើចូល Telegram របស់អ្នក។
- ក្រោយពេល Login ជោគជ័យ វានឹងចាប់ផ្ដើមឆ្លើយតបឆាតអូតូភ្លាម!
